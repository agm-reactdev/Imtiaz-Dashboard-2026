# 📊 Imtiaz Dashboard Analyze (Retail Inventory Dashboard)

An interactive and dynamic dashboard designed to analyze retail inventory, stock levels, and product performance. This project provides a clear visual overview of store operations, helping in making data-driven decisions for inventory management.

## 📸 Dashboard Preview
*(Yahan apne dashboard ki screenshot ka link daalein. Example: `![Dashboard Preview](dashboard_screenshot.png)`)*

## 🚀 Features & Key Metrics (KPIs)

*   **High-Level KPIs:** 
    *   Average Stock Level
    *   Total Stock Level (Sum)
    *   Total Months of Data
    *   Maximum Product Rating
*   **Category Analysis (Pie Chart):** Visualizes the total rating distribution across different product categories like Beverages, Staples, Home Care, Personal Care, and Snacks.
*   **Damage Risk Assessment (Area Chart):** Analyzes the sum of stock levels based on their damage risk (Yes/No), helping identify safe vs. vulnerable inventory.
*   **Detailed Inventory Table:** Provides a granular view including:
    *   Category & Status (Available / Not Found)
    *   Shopping Frequency (Monthly / Occasional)
    *   Item Found Status
    *   Sum of Reorder Points
*   **Dynamic Filtering:** Includes a "Quarter_Month" filter to slice the data and view specific timeframes.

The dashboard is built upon a retail dataset that includes fields like:
`Category`, `Status`, `Shopping_Frequency`, `Item_Found`, `Stock_Level`, `Damage_Risk`, `Rating`, `Reorder_Point`, and `Month_Number`.
